# 🛍️ Consumer Shopping Behavior Analysis

## 📌 Overview

This project analyzes consumer shopping behavior to identify purchasing patterns, customer preferences, product trends, and factors influencing customer purchases.

The analysis combines **Python, SQL, and Power BI** to transform raw customer data into meaningful business insights and actionable recommendations.

The project focuses on answering questions such as:

- Which customer segments generate the most revenue?
- Which products and categories are most popular?
- How do discounts influence purchasing behavior?
- Which products receive the highest customer ratings?
- What are the differences between shopping channels?
- Which products are most frequently purchased within each category?
- What factors may contribute to repeat purchases and customer loyalty?

---

## 📊 Dataset

The project uses a consumer shopping behavior dataset containing information related to:

- Customer demographics
- Product categories
- Products purchased
- Purchase amounts
- Review ratings
- Discounts
- Payment methods
- Shopping channels
- Previous purchases
- Purchase behavior

The dataset was first loaded and explored using Python before being cleaned and analyzed.
